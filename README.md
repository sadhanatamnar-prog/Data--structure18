Problem Statement

Develop a Gift Voucher Application using a Binary Search Tree (BST) to find whether two products have a combined price equal to a specified voucher value.

Introduction

A Gift Voucher Application helps customers identify two products whose combined prices match a given voucher amount. This project uses a Binary Search Tree (BST) to store product prices and find a suitable pair.

Objectives

1. To implement a Binary Search Tree using C++.
2. To insert product prices into the BST.
3. To find two products whose total price equals the voucher value.
4. To understand the practical application of BST.
   
Algorithm

1. Start the program.
2. Create an empty BST.
3. Insert all product prices into the BST.
4. Enter the voucher value.
5. Traverse the BST using inorder traversal.
6. Check whether any two product prices add up to the voucher value.
7. Display the matching pair or "No pair found".
8. Stop the program.
   
Applications

1. Gift voucher management systems.
2. Online shopping applications.
3. Product price matching.
4. Shopping budget management.
5. E-commerce platforms.
   
Advantages

1. Demonstrates the practical use of BST.
2. Organizes product prices systematically.
3. Helps identify matching product pairs.
4. Improves understanding of tree traversal and searching.

Conclusion

The Gift Voucher Application demonstrates how a Binary Search Tree can store product prices and help identify two products whose combined price matches a specified voucher value. This project improves understanding of BST insertion, inorder traversal, and pair searching in C++.
